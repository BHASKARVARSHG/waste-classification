# Waist Classification Deep Learning Model

## Overview

This project implements a deep learning model for waist classification using image data. The model processes input images and predicts the corresponding waist category.

## Features

- Deep learning-based image classification
- Data preprocessing and model training
- Prediction on new images
- Easy-to-use workflow

## Requirements

- Python 3.x
- TensorFlow / Keras
- NumPy
- OpenCV

pip install -r requirements.txt
